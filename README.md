# Сайт агента по недвижимости: объекты, услуги, блог, партнёрка

Шаблон сайта риелтора. Без внешних библиотек, нужен только Node.js 20 или новее. Сделан на движке сайта кинолога (kinolog-site).

## Запуск

Windows: дважды щёлкнуть start.bat. Любая система: `npm start`. Сайт на http://localhost:3000, админка на /admin. Пароль админки создаётся при первом запуске и лежит в config.json (на хостинге задаётся переменной ADMIN_PASSWORD, на демо стоит 1234).

## Что меняется в админке без правки файлов

- Объекты: тип (продажа, аренда), статус (в продаже, в резерве, продано), цена, район, комнаты, площадь, этаж, год, описание, преимущества, главное фото, галерея, видео, комиссия агента в процентах. Свои страницы, фильтры на витрине, микроразметка для поиска.
- Услуги и цены: название, цена или текст вместо цены («2% от цены сделки»), что входит, фото.
- Блог: статьи с текстом, фото и видео, черновики, дата, свои заголовок и описание для поиска.
- Об агенте: имя, фото, рассказ, преимущества, районы работы, галерея.
- Отзывы и сделки: показ только с согласия клиента.
- Сайт и SEO: контакты, город, домен, Яндекс Метрика, коды Вебмастера и Google, картинка для соцсетей.
- Фото: загрузка до 6 МБ.
- Оплата: ЮKassa, Робокасса, Т-Банк и CloudPayments (бета), тестовый режим. Онлайн можно оплачивать консультацию и проверку объекта; комиссия по сделке оформляется заказом из заявки, объект подставляет сумму по проценту.
- Партнёрка: три линии, ставки по сделкам и услугам отдельно (старт 20/3/2 % от комиссии агента), удержание 14 дней, минимальная выплата 3000 ₽.

## Демо-режим

Переменная DEMO_MODE=1 включает тёмную полосу сверху: сайт демонстрационный и такой же можно купить. Адрес «Узнать подробнее» задаёт DEMO_URL.

## Ниша

Стартовые данные лежат в content/*.json и попадают в базу при первом запуске. Объекты в них вымышленные, помечены «демо». Для другого агента замените файлы и удалите data/db.json.

## Публикация

Демо: Render (render.yaml, имя сервиса realtor-site-demo). Боевой сайт: сервер в РФ (папка deploy/, docs/ПУБЛИКАЦИЯ.md). На бесплатном тарифе Render база и загруженные фото стираются при перезапуске.
